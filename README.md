# easun-smt-MQTT
Simple system to obtain data from Easun/ISolar SMT-6.2kW-WIFI using RS232 and an ESP32 and forward to MQTT server. 

SMT series inverters use a RS232 protocol that has been documented at https://github.com/ljulina/esphome-easun-smt-iii
Most of the RS232 code has been pilfered from the same repository. Many thanks to Ladislav Julina for this.
